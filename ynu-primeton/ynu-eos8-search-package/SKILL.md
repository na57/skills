# 搜索构件包（EOS8 低代码平台）

## Overview

在云南大学低代码开发平台（普元 EOS8，`dev-idm.ynu.edu.cn`）**当前打开的 IDE** 左侧
「资源」面板顶部的搜索框输入关键字，资源树即时过滤。

**匹配规则（实测 2026-10-24）**：
- 包名**或包内任意子节点**（实体 / 页面 / 流程 / 服务）名包含关键字即命中；
- 命中子节点的包会**自动展开**显示匹配项（例：搜「测试」→「电子签章流程测试」包展开显示 实体→签章测试）；
- 无匹配时树区显示「**暂无数据**」；
- 搜索框 placeholder 为「**输入关键字搜索**」，输入即时过滤，**无需回车**（有约 1-2 秒防抖）。

**作用域铁律**：搜索是只读操作，但若作为其他写操作的定位步骤使用，仍须先向用户
确认目标应用 / 构件包，只操作用户指定的范围。

## When to use

- 用户要「找 / 搜 / 过滤 / 定位」某个构件包或包内资源，上下文是云大低代码平台（EOS8）。
- 其他 skill 执行前需要先在资源树中确认目标包存在或位置。
- 注意：平台需校园网或 WebVPN 环境。

## 参数

- **搜索关键字**（必填）：包名或资源名的任意子串，支持部分匹配
  （例：搜「测试」可命中「测试构件包」）。

缺参数 → 用 `AskUserQuestion` 询问，不要猜。

## Workflow

### Step 0 — 确认 IDE 已打开且已登录

1. `mcp__browser__browsers_list` 获取浏览器（取 `browser_id`），
   `mcp__browser__user_open_tabs` 列出已打开标签页。
2. **已有 IDE 页面**（URL 含 `/ide/index.html`，标题 Primeton-IDE）→
   `mcp__browser__tabs_claim` 接管，进 Step 1。
   - ⚠️ `appName` 参数值不固定（随用户所选应用变化），不要假设特定值。
3. **没有 IDE 页面或未登录** → 调用 `ynu-lowcode-login` skill，完成后回来认领 IDE 标签页。

### Step 1 — 截图定位搜索框

1. `mcp__browser__tab_focus` 置前，sleep 约 2 秒。
2. `mcp__browser__tab_screenshot` 截左上区域
   （clip `{x:0, y:0, width:300, height:400}`，png）。
3. 确认左侧「资源」面板与顶部搜索框可见。搜索框特征：
   placeholder「输入关键字搜索」，位于面板顶部
   （871×837 视口下文字区约 x=20..100, y=45；清除文字点击其**文字末尾**）。
4. ⚠️ IDE 的 DOM 快照把整棵资源树压成一个节点，搜索框无独立节点——
   **全程坐标操作 + 截图验证**，不要试图用 `dom_cua_click` 点它。

### Step 2 — 清空搜索框（框内已有文字时）

1. `mcp__browser__cua_execute` 一次序列：
   `click` 搜索框文字末尾（坐标按文字长度右移，宁右勿左）→
   `keypress ["End"]` → `keypress ["Backspace"]` ×6。
   - ⚠️ keys 数组单次最多 8 个动作；退格**必须先坐标点击聚焦**，否则按键无效。
   - ctrl/cmd+A 全选在此输入框**无效**，不要依赖；就用 End + 逐个退格。
2. sleep 约 2 秒后**单独调** `tab_screenshot` 验证：看到 placeholder
   「输入关键字搜索」= 已清空；没清干净就重复本步。
3. 搜索框本就为空 → 跳过。

### Step 3 — 输入关键字，树即时过滤

1. `mcp__browser__cua_execute` 一次序列：
   `click` 搜索框（约 x=60, y=45）→ `type` 关键字（支持中文）。
2. **无需回车**。sleep 约 2 秒。
3. `tab_screenshot`（clip `{x:0, y:30, width:290, height:300}`）验证过滤结果。

### Step 4 — 读取结果并汇报

1. 从截图读树，向用户报告命中的包清单；命中子节点时报「包 → 子节点」路径
   （例：电子签章流程测试 → 实体 → 签章测试）。
2. 显示「暂无数据」= 无匹配，如实报告并建议换关键字。
3. 汇报后**把搜索框清空**（重复 Step 2），恢复完整树，方便后续操作。

### Step 5 — 保留会话

保持标签页打开，登录态与页面状态供后续 skill 复用。不要为清理而关闭页面。

## Notes / gotchas

- **同序列截图是旧的**：`cua_execute` 里最后附带的 screenshot 往往拍不到刚发生的
  UI 变化（渲染 + 防抖延迟）。铁律：操作完 → `sleep 2` → **单独调**
  `tab_screenshot` 验证，不要相信同序列截图。
- **原始按键需要焦点**：Backspace / End 只有在坐标点击把焦点落进输入框后才生效；
  一次点击失效就重试点一次再发按键。
- **DOM 快照压缩**：资源树、搜索框均无独立 DOM 节点，一律坐标操作。
- **坐标基于视口**：本文坐标来自 871×837 视口。窗口尺寸不同时，先截全图按
  「资源」面板顶部重新定位搜索框。
- **CDP 输入超时频发**：窗口在后台时必现。对策：每次操作前 `tab_focus` 置前并
  sleep 约 2 秒；超时后等 5-15 秒再 focus 重试，通常第 2-3 次恢复。
- **连接偶发失效**：报 `tab does not exist` 时重新走
  `browsers_list` → `user_open_tabs` → `tabs_claim` 即可恢复，页面状态不丢。
- **验证以截图为准**：截图直接回传图像（2026-10-24 起模型已支持读图），
  截图会同时落盘 `/Users/na57/.workbuddy/blobs/...`。

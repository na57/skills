## 网关

- 另一个 `aigc-api.ynu.edu.cn`（CosyVoice）当时持续 502，已弃用。

## 音色克隆参数名

试过 `reference_audio`、`speaker_wav`、`audio_prompt`、`prompt_audio` —— **全部静默
忽略**，HTTP 200、正常出声，但音色依旧随机。唯一生效的是：

```
ref_audio: "data:audio/mpeg;base64,<base64>"   # 不是裸 base64，也不是文件路径
ref_text : "<样本音频逐字原文>"
```

传裸 base64 或本地路径 → 400。

## F0 实验（客观证据）

方法：ffmpeg 转 16 kHz 单声道 PCM → numpy 分帧自相关估 F0 → 取有声帧中位数。

| 配置 | 各条 F0（Hz） | 标准差 |
| --- | --- | --- |
| 无 ref_audio | 四处乱跳 | **37.93** |
| 有 ref_audio（样本：3-higgs-平台听力训练在用.mp3） | 集中在 190 上下 | **2.30** |

样本自身 F0 = 205.1 Hz。成片整体比样本低 5–20 Hz 是语速语调差异，不是音色漂移。

判据：标准差 < 8 Hz 判克隆生效；> 15 Hz 判音色随机。

## 音色选项（Qwen3-TTS 分支）

- `dylan`：北京普通话男声，稳定，自然度一般
- `uncle_fu`：成熟男声

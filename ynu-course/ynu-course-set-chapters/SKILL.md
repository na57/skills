# 云大学堂 - 设置章节内容

## 用途

在课程管理后台的「章节内容」页搭建课程章节骨架：**章 → 小节** 两级结构，可新建、改名、展开核对。本 skill 只管章节目录本身，不往节里上传讲义/课件/视频，不发布课程，不删除章节或课程。

## 前置条件

- 使用 WorkBuddy 内置浏览器（WorkBuddy Browser），通过 `mcp__browser__*` 工具操作。若工具未直接可用，先用 ToolSearch 加载：`tabs_new` / `tab_goto` / `tab_screenshot` / `cua_click` / `cua_move` / `cua_type` / `cua_keypress` / `cua_execute` / `dom_cua_get_visible_dom` / `tabs_finalize`。
- 用户需已登录云大学堂后台（本会话浏览器通常保留登录态）。若跳到统一登录页 `unifiedlogin/#/multiplelogin`，提示用户自行登录，不要代填凭据。
- **必须先打开目标课程**：若当前不在目标课程的课程管理页，先调用 `ynu-course-open-manage` skill 打开，拿到形如 `#/editcourse/moocbaseinfo?id=<课程ID>&type=<类型>&sm=1` 的页面后再继续。用户没指明哪门课，同样交给 `ynu-course-open-manage` 询问。

## 关键操作约定（务必先读，都是实测踩过的坑）

### 1. 输入框是「插入」不是「替换」，全选快捷键无效

- `cua_type` / `dom_cua_type` 把文本**插到光标当前位置**，不会替换已有内容。
- `Meta+A` / `Control+A` / `MetaOrControl+A` 在本浏览器环境**都不生效**（有的报 unsupported，有的无反应）。不要指望"全选后输入"来改名。
- **改已有名称的正确做法**（就地编辑场景）：
  1. 点输入框，把光标定位到**文本末尾**（点文字右侧空白处，或按 `End`）。
  2. 按 `Backspace` N 次（N = 原文本字符数）把内容清空。
  3. 确认截图里计数变成 `0/99`，再 `cua_type` 输入新文本。
  4. **发现文字被插到中间**（如出现"第一章认识这条链"）→ 点 ✗ 取消，重新点编辑图标再来一次，不要在错乱基础上修补。
- 输入框右侧有字符计数 `N/99`，**用它核对输入是否正确**（例："认识这条链"应显示 `5/99`）。这是最可靠的校验手段。

### 2. 两种编辑形态要分清

| 操作 | 形态 | 控件 |
|---|---|---|
| 新建章 / 新建小节 | **弹窗**「编辑章」/「编辑节」 | 名称输入框 + 「取 消」「确 定」按钮 |
| 修改已有章名 / 节名 | **就地编辑**（行内出现输入框） | 输入框 + ✓（保存） / ✗（取消） |

- 弹窗出现有**淡入动画**：点按钮后立刻截图会截到半透明状态，位置会偏。稳妥做法：点完按钮**再截一张**确认弹窗稳定后再点输入框。
- 弹窗稳定后，名称输入框、确定按钮位置基本固定（994×968 视口下：输入框约 y=472，确定约 y=561），但仍以当次截图为准。

### 3. 小节行要悬停才出现操作图标

- 小节默认只显示「1.1 名称」文字，编辑图标是隐藏的。
- 先把鼠标 `cua_move` 到该小节文字上，图标才出现：眼睛（预览）、铅笔（编辑）、垃圾桶（删除）。
- 章行的编辑图标（铅笔）常驻显示，但章行文字点击是折叠/展开。

### 4. SPA 与滚动

- 单页应用，每次弹窗出现、页面变化后**重新截图**，不复用旧坐标/旧节点。
- 内容区 `cua_scroll` 有时不生效。要让下方章节上移，改为**折叠上方的章**（点章名前的三角 ▶/▼）。

## 工作流程

### 第 1 步：确定章节结构（向用户确认，不要猜）

章节结构不能自行编造。来源二选一：

- **用户直接给出**：请用户按「章 → 小节」层级列出，例如
  ```
  第1章 认识这条链
    1.1 为什么会上当
    1.2 攻击链六步
  第2章 四个检查点
    2.1 谁发的
    ...
  ```
- **用户说"看项目/大纲"**：从项目里的大纲文件读取（如 `course.json` 的 `stages`＝分组、`chapters`/`plan`＝讲次）。若一个大纲同时有"分组"和"讲次"两层，**映射方式必须问用户拍板**（例：3 组 / 8 讲，是"3 章 8 节"还是"8 章平铺"），不要替他决定。

拿到结构后，简述一遍并说明将从哪个节开始操作，再动手。

### 第 2 步：进入「章节内容」页

1. 确认当前在目标课程管理页（URL 含 `#/editcourse/...`）。
2. 点左侧菜单「章节内容」。
3. 截图：新课程默认已有「第1章 第一章」和「1.1 第一节」各一个（占位骨架）。

### 第 3 步：改名已有的第 1 章与 1.1 节

先复用默认骨架，而不是删了重建：

1. 点第 1 章行的铅笔图标 → 就地编辑框出现。
2. 按「关键约定 1」清空并输入第 1 章标题 → 截图核对计数 → 点 ✓ 保存。
3. 鼠标移到「1.1 第一节」上，点出现的铅笔图标 → 同样清空并输入第 1 个小节标题 → 点 ✓ 保存。
4. 每改完一项，截图确认名称已生效（注意有写入延迟，必要时再截一张）。

### 第 4 步：新建其余章、其余小节

- **新建小节**：点目标章下方的「小节」按钮 → 弹窗「编辑节」→ 等弹窗稳定 → 点名称输入框直接输入（新框是空的，无需退格）→ 点「确 定」。节号自动递增（1.2、1.3…），输入框里**只填标题文字，不要带"1.2"这种编号**。
- **新建章**：点顶部「添加章」按钮 → 弹窗「编辑章」→ 等弹窗稳定 → 输入章标题 → 点「确 定」。章号自动递增（第2章、第3章…），同样只填标题文字。
- 严格按结构从上到下建；每建完一项截图确认。

### 第 5 步：展开核对并交付

1. 逐个点章名前的三角，展开所有章。
2. 截图核对：章数、每章节数、每个名称是否与第 1 步确定的结构完全一致（对照字符计数与文字）。
3. 向用户报告最终章节树（章 + 全部节名）。
4. 用 `tabs_finalize` 把该标签页标记为 `deliverable` 保留，方便用户继续操作。
5. 明确告知：目前只是**空章节骨架**，各节的教学内容尚未上传，课程也未发布——这两件事不在本 skill 范围内。

## 失败处理

- 输入被插到光标中间、文字错乱 → 点 ✗ / 「取 消」放弃，重新进入编辑，用退格清空后重输。
- 全选快捷键无效 → 不要反复试，直接用"点末尾 + 退格 N 次 + 输入"。
- 点按钮后对话框位置不对/半透明 → 多截一张等动画结束再操作。
- 目标章在页面下方点不到 → 折叠上方其他章让它上移。
- 小节行的编辑图标点不到 → 先把鼠标移到该行文字上让图标出现。
- 找不到目标课程或没登录 → 回到 `ynu-course-open-manage` / 提示用户登录。
- 任何发布、删除章节/课程、上传教学内容的请求 → 说明不在本 skill 范围，不要执行。

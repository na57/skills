# 云大学堂 - 编辑课程信息

## 用途

在课程管理后台编辑课程的基本信息：进入编辑态 → 按用户要求修改字段 → 保存或取消。本 skill 只处理"课程信息设置"标签下的基本信息编辑，不处理章节内容、教学大纲、课程资料等其他模块。

## 前置条件

- 使用 WorkBuddy 内置浏览器（WorkBuddy Browser），通过 `mcp__browser__*` 工具操作。
- 用户需已登录云大学堂后台。
- **需要先打开目标课程**：若当前不在课程管理页，先调用 `ynu-course-open-manage` skill 打开目标课程，拿到形如 `#/editcourse/moocbaseinfo?id=<课程ID>&type=<类型>` 的页面后再继续。用户没指明哪门课时，同样交给 `ynu-course-open-manage` 处理询问。

## 关键操作约定

- **编辑态切换**：页面默认是查看态，右上角是"编辑"按钮；点它后按钮组变为"保存"和"取消"。只有在编辑态下字段才可修改。
- **DOM 与截图配合**：课程编辑页 DOM 通常能抓到（按钮、tab、输入框），优先用 DOM 操作；页面较宽时截图用 `tab_screenshot` 的 `clip` 参数截取区域（全页截图可能超过大小限制），配合 `cua_click` 坐标点击。
- **保存 vs 取消**：修改完成后点"保存"写入；点"取消"放弃所有改动并退回查看态。用户没明确要取消时，默认保存。
- 注意页面上可能存在多组"保存/取消"按钮（顶部编辑态一组；下方内容区另一组"更新/保存/取消"）。本 skill 用**右上角编辑态的那组**按钮，即与"编辑"按钮同一位置的一组。

## 工作流程

### 第 1 步：确认要修改的字段和新值

向用户确认要改哪些字段、改成什么值。**若用户没说清楚改成什么，先询问，不要自行猜测或填充。** 用户说"随便改改测试"之类时，明确告知会用测试值并询问是否继续。

可编辑的基本信息字段（在"课程信息设置"标签下）：
- 课程名称（有字数限制，如 7/50）
- 学科专业、开课时间/开课学期、开课学院、适用专业、培养层次、语种、课程等级
- 标签（输入框按 Enter 回车键创建标签）
- 课程封面（点"编辑封面"）
- 课程介绍等富文本内容编辑区

### 第 2 步：进入编辑态

1. 确认当前处于目标课程的课程管理页（URL 含 `#/editcourse/...`）。
2. 读取 DOM 或截图，找到课程信息设置区右上角的"编辑"按钮并点击。
3. 验证：右上角按钮变为"保存"和"取消"，即进入编辑态。

### 第 3 步：修改字段

按第 1 步确认的内容逐项修改：

- 优先用 DOM 定位输入框、下拉框等元素并填入新值；每个字段改完可截图确认。
- 标签类字段需在输入框输入后按 Enter 创建。
- 富文本区用 DOM 的 contenteditable 或工具栏按钮操作。
- 不要改动用户没提到的字段，避免误改。

### 第 4 步：保存或取消

- 用户要求取消，或修改过程中用户改主意 → 点右上角"取消"，放弃所有改动，退回查看态。
- 否则 → 点右上角"保存"，等待写入完成。

### 第 5 步：验证并报告

- 点"保存"后：截图确认已退回查看态（右上角恢复"编辑"按钮），且修改的字段显示为新值；若字段被折叠或不在首屏，滚动到对应位置确认。
- 点"取消"后：确认字段恢复为原值，右上角恢复"编辑"按钮。
- 向用户报告：改了哪些字段、是保存还是取消、最终结果。

## 失败处理

- 若点"编辑"后字段仍不可修改，检查是否点到了其他标签页（如"教学团队管理"），切回"课程信息设置"标签。
- 若保存后字段没变化或有校验错误提示（如名称超长、必填项为空），截图查看提示，按提示修正后重试；仍失败则告知用户具体错误，不要强行绕过。
- 若课程不是未发布状态（如"已发布"），编辑可能有额外限制，按页面提示处理并向用户说明。
- 本 skill 不涉及发布、删除课程，不要执行这类操作。

# 云大学堂 - 创建公开课

## 用途

在云大学堂后台（course.ynu.edu.cn）创建一门**公开课**，走"不使用课程包，直接开课"路径。本 skill 只负责创建公开课这一件事，不处理班级课、微课、培训课等其他课程类型。

## 前置条件

- 使用 WorkBuddy 内置浏览器（WorkBuddy Browser）操作，通过 `mcp__browser__*` 工具完成。
- 用户需已在浏览器中登录云大学堂后台。打开后台地址若跳到统一登录页（`unifiedlogin/#/multiplelogin`），提示用户自行输入用户名和密码登录，不要代为输入或猜测凭据。
- 本会话浏览器通常保留登录态，打开后台可直达工作台首页。

## 关键操作约定

- **SPA 页面**：这是单页应用，页面跳转后元素标识会失效。每次弹窗出现、页面变化后都要重新读取 DOM，不要复用旧节点。
- **优先 DOM，兜底截图**：先用 `mcp__browser__dom_cua_get_visible_dom` 读取节点并用 `dom_cua_click` / `dom_cua_type` 操作；DOM 抓不到目标时再用 `tab_screenshot` + `cua_click` 坐标点击。
- 首次打开工作台可能弹出右侧"主页功能介绍"引导栏，用坐标点击右上角 ×（约 674,26）关闭；不影响本流程时可忽略。

## 工作流程

### 第 1 步：确定课程名称

向用户确认要创建的公开课名称。**若用户未提供课程名称，必须先询问用户，拿到名称后再继续**，不要自行编造或填充测试名称。用户明确说"随便建一个测试"之类的情况下，才使用一个明显可识别的测试名（如"测试公开课-可删除"），并在完成后告知用户实际使用的名称。

### 第 2 步：进入公开课页面

导航到公开课列表页：

```
https://course.ynu.edu.cn/learn/workbench/#/course/mooccourse
```

若标签页标识失效（报 "tab does not exist"），从 `mcp__browser__browsers_list` 重新开始：重新获取可用标签页（`tabs_list` / `user_open_tabs`），用 `tabs_claim` 接管后再操作。

确认页面左侧导航"课程 > 公开课"处于选中状态。

### 第 3 步：点击"新建"

读取 DOM，找到按钮文本为"新建"的按钮并点击。点击后弹出"添加课程"对话框。

### 第 4 步：填写课程名称并确定

在"添加课程"弹窗中：

1. 重新读取 DOM，定位 placeholder 为"请输入课程名称"的 `input`（required=true）。
2. 点击该输入框，填入第 1 步确定的课程名称。
3. 可截图确认名称填写无误。
4. 点击"确 定"按钮（注意按钮文本中间可能带空格）。

### 第 5 步：选择"不使用课程包，直接开课"

确定后弹出"选择课程资源包"对话框。重新读取 DOM，找到文本为"不使用课程包，直接开课"的按钮并点击。点击后按钮会短暂进入加载状态，等待其完成。

### 第 6 步：验证结果

- 对话框关闭、返回公开课列表页，且列表首位出现刚才填写的课程名称，即视为创建成功。
- 截图确认，并向用户报告：课程名称、创建者、当前状态（通常为"第1期 进行中"、"未发布"）。
- 新建公开课默认为**未发布**状态，不要擅自点击"发布"。

## 失败处理

- 若点击"确定"后没有弹出"选择课程资源包"对话框，截图查看是否有校验错误提示（如名称为空、重名），按提示修正后重试。
- 若名称重复，提示用户换一个名称，不要自行加后缀绕过。
- 任何提交类操作（发布、删除等）都不在本 skill 范围内，不要执行。

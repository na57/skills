# 云大学堂 - 打开课程管理后台

## 用途

从云大学堂后台首页的"我的课程"列表中找到目标课程并点击，进入该课程的课程管理后台（课程编辑页）。本 skill 只做"打开课程管理后台"这一件事，不修改课程任何内容。

## 前置条件

- 使用 WorkBuddy 内置浏览器（WorkBuddy Browser），通过 `mcp__browser__*` 工具操作。
- 用户需已登录云大学堂后台。打开后台若跳到统一登录页（`unifiedlogin/#/multiplelogin`），提示用户自行输入用户名和密码登录，不要代为输入或猜测凭据。本会话浏览器通常保留登录态。

## 关键操作约定

- **SPA 页面**：单页应用，跳转后节点标识失效，每次页面变化后重新读取状态，不复用旧节点。
- **首页 DOM 抓不到主体**：后台首页 `/#/home` 的 DOM 快照通常只能返回顶部链接，抓不到"我的课程"列表。直接用截图（`tab_screenshot`）+ 坐标点击（`cua_click`）操作，不必反复尝试 DOM。
- **课程在新标签页打开**：点击课程卡片不会改变当前标签页的 URL，而是**新开一个标签页**打开课程管理页。点击后要用 `user_open_tabs` / `tabs_list` 找到新标签页确认，不要误以为没生效而重复点击。
- 标签页标识失效（报 "tab does not exist"）时，从 `mcp__browser__browsers_list` 重新走 `user_open_tabs` → `tabs_claim` 流程获取控制权。

## 工作流程

### 第 1 步：确定目标课程

判断用户想打开哪门课程：

- 用户在指令中给出了课程名称 → 按名称匹配。
- 用户没指明、或描述模糊无法唯一判断 → **必须先询问用户**，列出"我的课程"列表里可见的课程名让用户选择，不要自行猜测或用最近一门课代替。

### 第 2 步：进入后台首页

导航到：

```
https://course.ynu.edu.cn/learn/workbench/#/home
```

页面中部是"我的课程"区块，带"全部 / 班级课 / 微课 / 公开课"筛选标签，卡片显示课程名称与创建者，右上角标注"已发布"或"未发布"。首页默认展示的课程数量有限（实测约 3 门），如目标课程不在其中，可点击"全部"或切换到对应课程类型标签，必要时进入"课程"左侧导航的完整列表页查找。

### 第 3 步：定位并点击目标课程卡片

1. 用截图查看"我的课程"区块，按第 1 步确定的名称找到对应卡片（卡片上有课程名文字）。
2. 用 `cua_click` 点击该卡片的课程名称或封面区域。
3. 点击后用 `user_open_tabs` 检查是否出现新的标签页，其 URL 形如：

   ```
   https://course.ynu.edu.cn/learn/workbench/#/editcourse/moocbaseinfo?id=<课程ID>&type=<类型>&sm=1
   ```

   出现即表示已成功进入课程管理后台。

### 第 4 步：验证并交付

- 确认新标签页 URL 为 `#/editcourse/...` 且包含课程 ID。
- 向用户报告：已打开哪门课程的课程管理后台，以及它在哪个标签页。
- 用 `tabs_finalize` 保留该标签页（status 设为 `deliverable`），方便用户直接操作。
- 不要修改、发布或删除课程的任何内容。

## 失败处理

- 若点击后没有新标签页出现，可能是点在了卡片非交互区域，重新截图后点击卡片上的课程名称文字重试。
- 若列表里找不到用户指定的课程，告知用户当前可见课程，询问是否切换课程类型标签或到完整课程列表页查找。
- 若新标签页打开但不是课程编辑页（例如跳到登录页），按前置条件处理登录，登录后重试。
